# Ritmo

App pessoal de rotina, hábitos, treino, estudos e finanças, com progressão de rank estilo Valorant.

- Funciona 100% offline, em um único arquivo HTML.
- Os dados ficam salvos só no navegador do próprio aparelho (localStorage).
- Faça backup em ⚙️ Dados → "Baixar Backup".

## Como usar no celular

- **Android (Chrome):** menu ⋮ → Adicionar à tela inicial.
- **iPhone (Safari):** Compartilhar → Adicionar à Tela de Início.

## Funcionalidades

- Hábitos diários e blocos de rotina com RR
- Hobbies com meta semanal
- Treino com histórico de cargas e peso
- Provas, prazos e tarefas
- Finanças mensais com gastos fixos recorrentes
- Dia, semana e mês fecham sozinhos
